# EGGIM 라벨링 도구 (단일 HTML)

내시경 이미지에 **부위 · 화질 · IM 등급**을 빠르게 라벨링하고 CSV로 내보내는 브라우저 도구입니다.
설치·서버 불필요, **이미지는 전부 로컬에서만 처리**되어 외부로 전송되지 않습니다(PHI 안전, 오프라인 동작).

## 여는 방법 (둘 중 편한 쪽)

- **A. 웹 링크(git 불필요)** — 게시된 아티팩트 URL을 Chrome/Edge로 엽니다. 이미지는 여전히 로컬에서만 처리됩니다.
- **B. 로컬 파일** — 이 `index.html`을 내려받아 Chrome/Edge로 엽니다(더블클릭).

## 사용법

1. `index.html`(또는 웹 링크)을 브라우저에서 엽니다(Chrome/Edge 권장).
2. **📁 폴더 열기** → 내시경 이미지 폴더 선택.
   - 폴더 구조 `루트/환자ID/이미지.jpg` → 하위 폴더 이름이 `patient_id`가 됩니다.
   - 평면 폴더면 파일명 `_` 앞부분이 `patient_id`가 됩니다.
3. 이미지를 보며 라벨링(키보드 권장):

   | 항목 | 키 | 값 |
   |---|---|---|
   | 부위 | `1`~`6` | 전정부 소만/대만 · 각부 · 체부 소만/대만 · 해당없음 |
   | IM 등급 | `7` `8` `9` | 0 없음 · 1 국소(≤30%) · 2 광범위(>30%) |
   | 화질 부적정 | `0` | 흐림/거품/부적절 (등급 자동 비움) |
   | 이전 / 다음 | `←` / `→` 또는 `Space` | |
   | 내보내기 | `E` | |

4. **💾 CSV 내보내기** → `eggim_labels.csv` 저장.

## 특징

- **자동 저장**: 브라우저 localStorage에 계속 저장되어 창을 닫아도 라벨이 남습니다(같은 폴더 재선택 시 복원).
- **📄 CSV 이어서**: 이전에 내보낸 CSV를 불러와 다른 PC에서 이어 작업.
- **완료 시 자동 다음** / **미라벨만** 보기 옵션.
- 부위별 진행 현황·미라벨 수 실시간 표시.

## 출력 CSV 스키마 (학습 파이프라인과 일치)

`image_path, patient_id, seq_index, site, quality_ok, im_grade`

→ 그대로 `python -m eggim.train site --manifest eggim_labels.csv ...` 에 투입 가능합니다.
`scaffold_manifest.py`가 만든 매니페스트와 동일한 컬럼입니다.

## 라벨링 팁

- **소만 vs 대만**이 애매하면 무리하지 말고 `해당없음(6)` 또는 화질 부적정으로 빼는 것이 라벨 노이즈를 줄입니다.
- 초기 시드는 **환자 100~200명 × ~10장**이면 부위분류기 학습을 시작할 수 있습니다.
- 전체의 10~20%는 **두 명이 이중 라벨링**해 판독자 간 일치도(κ)를 측정하세요.
